## これは何か

UTF-8 BOM を正確に 1 つ付与する（多重 BOM も正規化）。`check-encoding.py --fix` の BOM 部分だけを行う軽量版

## なぜ作られたか

モデル非依存化の一環（2026-07-02）。**BOM 復元のための Python パターンをモデルが都度組み立てる手順**が精度依存だったため、スクリプトに固定した（ADR-001）
