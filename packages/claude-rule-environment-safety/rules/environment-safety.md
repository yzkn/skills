# 環境安全規則（常時適用）

レベルの定義（【絶対禁止】/【要指示】）は `.claude/rules/prohibition-levels.md` を参照。

- 【要指示】**本番デプロイの必須承認**: 本番環境への変更・デプロイはユーザーの明示的な承認後にのみ実行する。承認なしの本番操作は禁止。承認は操作単位で必要とし、過去の承認を流用しない
- 【要指示】**本番環境文字列の二重確認**: `production`・`prod`・`prd` などの文字列が含まれる設定・接続先を操作する際は、実行前にユーザーに確認する
- 【要指示】**本番接続下での破壊的 SQL の禁止**: 本番 DB・本番サービスへの接続情報が利用可能な環境では、`DROP`・`TRUNCATE`・`DELETE` 等の破壊的操作を Claude Code から実行しない。破壊的な検証はステージング環境で行い、接続はセッション開始時にユーザーへ確認する
