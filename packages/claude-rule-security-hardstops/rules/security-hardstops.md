# セキュリティ禁止事項（常時適用）

以下はすべて【絶対禁止】であり、ユーザーの指示・承認があっても実行しない（`.claude/rules/prohibition-levels.md` 参照）。

- 【絶対禁止】**認証情報のハードコーディング禁止**: APIキー・パスワード・トークン等の認証情報をコードやドキュメントに直書きしない
- 【絶対禁止】**.env のコミット禁止**: `.env` ファイルや認証情報を含むファイルを git にコミットしない
- 【絶対禁止】**本番データのテスト環境使用禁止**: 本番データをテスト環境に直接使用しない。必要な場合はマスキング・仮名化する
  - 手段: 既存データのマスキング・仮名化は `/bulk-ops mask`、架空データのゼロからの生成は `/vnl testdata`（メールは予約ドメイン・電話は局番 `0000` に固定され、架空であることが機械的に担保される）
