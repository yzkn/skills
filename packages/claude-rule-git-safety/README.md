# git-safety

Git 操作のすべての場面で常時適用する禁止事項と必須確認。

## これは何か

コミット・push・`--no-verify` の禁止事項、コミット前の機密情報チェック、**コミット後の証跡の取りこぼし確認**、ダミー値の作り方

## なぜ作られたか

初期構成のルールを 2026-06-23 に切り分けて独立ファイル化。その後 2 度の失敗で加筆した。① 自動コミットがインデックス全体を巻き込む事故（ADR-023）→ 例外条件に「コミットにパス指定を付ける」を追加 ② 証跡の自動コミットが gitleaks に 7 日間拒否され続けたことに誰も気づかなかった（ADR-034・ADR-035）→ 取りこぼし確認とダミー値の登録簿運用を追加

## 導入

```sh
mkdir -p .claude/rules
cp rules/git-safety.md .claude/rules/
```

常時適用したい場合は `CLAUDE.md` に `@.claude/rules/git-safety.md` の行を追加する。frontmatter に `paths:` があるルールは `@` 行に**加えない**（加えると常時ロードになり、条件付きの意味が失われる）。
