# アプリ実装テーマデータベース

## 凡例

### 難易度

| 難易度 | 目安 | 対象技術レベル |
|---|---|---|
| 低 | 単純な CRUD / 計算 / 表示のみ。外部 API 連携なし | 初めて〜1本経験 |
| 中 | 外部 API 連携 / 複数エンティティ管理 / 状態管理が必要 | 1〜2本経験 |
| 高 | リアルタイム処理 / AI 統合 / 複雑なゲームロジック / 高度な非機能要件 | 中級以上 |

### プラットフォームタグ

| タグ | 意味 |
|---|---|
| 汎用 | Power Apps / Web / Python / .NET など多くのプラットフォームで実装できる |
| Power Apps | Power Apps Canvas App での実装が典型的 |
| Power Automate | Power Automate クラウドフローが中心 |
| Copilot Studio | Copilot Studio によるチャットbot実装が典型的 |
| Power Platform | 複数の Power Platform 製品の組み合わせが必要 |
| Web | ブラウザ上の動作が本質的（Canvas / Geolocation など Web API を活用） |
| Python | Python スクリプト / ライブラリが適している |
| デスクトップ | OS のデスクトップ機能へのアクセスが必要 |
