# complexity-analyzer

コード複雑度診断エージェント。循環的複雑度・認知的複雑度・クラスサイズ・ネスト深度を静的解析し、閾値超過箇所を優先度付きで一覧化する。perf-analyzer の性能リスクに対し保守性リスクを担う。

> このリポジトリは、Claude Code 用のプロジェクトテンプレート `claudecode-pm-starter-kit`（非公開）の資産を **1 項目 = 1 リポジトリ**の形に切り出したものである。切り出しは機械的に行っており、**本文中の相互参照は元リポジトリのパスのまま残っている場合がある**（下記「単体利用時の注意」を参照）。元リポジトリは公開していないため、本文が挙げる ADR・コミットなどの記録は参照できない。

## これは何か

循環的複雑度・認知的複雑度・ネスト深度・クラスサイズを静的解析し、リファクタリング優先度を提示

## なぜ作られたか

同上（記録なし）。`perf-analyzer` の性能リスクに対し**保守性リスク**を担う役割分担

## 導入

```sh
mkdir -p .claude/agents
cp agents/complexity-analyzer.md .claude/agents/
```

**`.claude/agents/` はフラットに置く**（サブディレクトリを作っても登録機構は再帰的に走査するため、無効化の目的では使えない）。

## 使い方

Agent ツールで `subagent_type: "complexity-analyzer"` を指定して起動する。
