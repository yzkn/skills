図と数式

インライン SVG の図

自作図は黒一色の線画を基本とし、線色に currentColor を使います。ダークモードでも線が消えません。

数式（MathML）

下の数式が E = mc^2 という生の文字列ではなく組版された形で見えていれば、ブラウザの MathML 描画が効いています。数式にカーソルを合わせると LaTeX 原文のコピーボタンが出ます。

E=mc2E = mc^2

インライン数式は α+β\alpha + \beta のように地の文へ埋め込みます。上の 2 つはいずれも pandoc -f markdown -t html --mathml の実出力です。

シンタックスハイライト

以下は pandoc -f markdown -t html の実出力をそのまま貼ったものです。キーワードが青、文字列が赤、コメントが灰色の斜体になっていればテンプレートの CSS が効いています。
