## 3. 導入手順

```sh
# 導入先のプロジェクトルートで実行する
mkdir -p .claude/skills
cp -r skills/governance .claude/skills/
```

**スキルは必ずディレクトリ形式（`.claude/skills/governance/SKILL.md`）で置く。** フラットな `.md` として置くとスキル登録機構に載らず、自動適用も `/governance` での呼び出しもできない。

### 3-1. 呼び出し方

- 自動適用: frontmatter の `description` に一致する依頼があったとき
- 明示呼び出し: `/governance`

**自動適用は `description` だけでは安定しない。** 元リポジトリでの実測では、発動を左右するのは説明文の充実度より**常時適用ルールからスキル名を名指しすること**だった。確実に使いたい場合は、導入先の `CLAUDE.md` かルールから `/governance` を名指しする。

## 4. 内容の構成

本体（`skills/governance/SKILL.md`）の見出し構成:

- 本スキルの目的
- 用語定義
- ガバナンス管理の事前準備（ゴール設定）
- 標準作業項目一覧
- 各作業項目の詳細ガイド
  - 事前調査
  - 提案
  - 契約締結
  - プロジェクト計画
  - Microsoft 365テナント 設計・導入
  - Power Platform環境 設計・運用
  - ガイドライン資料整備
  - 教育
- 利用可能なテンプレート
