# api-spec-generator

API 仕様書生成エージェント。既存のコントローラー・ルーター・DTO から OpenAPI 3.0 仕様書（YAML）を逆生成する。api-guide が設計規約の参照であるのに対し実装済みコードの仕様書化を担う。

> このリポジトリは、Claude Code 用のプロジェクトテンプレート `claudecode-pm-starter-kit`（非公開）の資産を **1 項目 = 1 リポジトリ**の形に切り出したものである。切り出しは機械的に行っており、**本文中の相互参照は元リポジトリのパスのまま残っている場合がある**（下記「単体利用時の注意」を参照）。元リポジトリは公開していないため、本文が挙げる ADR・コミットなどの記録は参照できない。

## これは何か

コントローラー・ルーター・DTO から OpenAPI 3.0 仕様書を逆生成（未ドキュメント化エンドポイントの指摘付き）

## なぜ作られたか

同上（記録なし）。`api-guide` が設計規約の参照であるのに対し**実装済みコードの仕様書化**を担う

## 導入

```sh
mkdir -p .claude/agents
cp agents/api-spec-generator.md .claude/agents/
```

**`.claude/agents/` はフラットに置く**（サブディレクトリを作っても登録機構は再帰的に走査するため、無効化の目的では使えない）。

## 使い方

Agent ツールで `subagent_type: "api-spec-generator"` を指定して起動する。

## 収録ファイル

- `agents/api-spec-generator.md`（8.0 KB）
