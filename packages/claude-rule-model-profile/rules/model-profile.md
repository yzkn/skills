# モデル別コンテキストプロファイル（常時適用）

本リポジトリの規約は、どのモデルでも安全に動くよう基礎知識まで明示的に書いてある。高性能モデルにはその一部が冗長なため、使用モデルに応じて読む範囲を切り替える。

## 1. 使用モデルの確認

- セッションの最初の応答の前に、自分が動作しているモデル名を確認してプロファイルを決める（モデル名は自身のシステムプロンプトに記載。ユーザー側は `/status` で確認できる）
- モデルは `/model` や設定変更でセッション途中でも切り替わる。**切り替わったと分かった時点で判定し直す**
- 最初の応答（および切替を認識した直後の応答）の冒頭に 1 行で出力する: `使用モデル: <モデル名>（<プロファイル名>プロファイル）`

## 2. プロファイル

| プロファイル | 対象モデル | 読み込み方針 |
|---|---|---|
| **簡潔** | Fable 5 / Opus 5、およびこれらと同等以上の後継 | `profile:standard-only` マーカーで囲まれた区間を読み飛ばす。`*-details.md` は必要になった時点でのみ Read する |
| **標準** | 上記以外（Sonnet 系・Haiku 系を含む） | 読み飛ばさない。作業に関係する `*-details.md` は着手前に Read する |

**迷ったら標準を適用する。** モデル名が判別できない場合・世代が不明な新しいモデル名の場合も標準とし、誤りは「読みすぎ（トークン増）」の側に倒す。ユーザーが明示的にプロファイルを指定した場合はそれに従う。

## 3. マーカーの意味

冗長箇所は HTML コメント（`profile:standard-only` の開始マーカーと `/profile:standard-only` の閉じマーカー）で囲まれており、Markdown の表示には現れない。簡潔プロファイルでは、この区間の**内容の適用は求められるが、逐語の再読・逐条の確認は不要**とする。

## 4. 読み飛ばし・分離の対象外【重要】

以下はプロファイルに関わらず**常に全文をロードし、全文を適用**する。

- `prohibition-levels.md`・`git-safety.md`・`security-hardstops.md`・`environment-safety.md`・`safe-file-ops.md`・`adversarial-review.md`・`external-resources.md`・`third-party-licenses.md`（いずれも `.claude/rules/`）
  - ただし `.claude/docs/third-party-licenses-details.md`（ライセンス分類の一覧表）は例外で、常時ロードせず**分類の判断が必要になった時点で Read する**。判断基準・【要指示】の範囲は常時適用側の `third-party-licenses.md` に残してある
- 【絶対禁止】/【要指示】ラベルの付いた記述、承認・確認を要求する記述
- 本リポジトリ固有の情報（ディレクトリの役割・フック構成・成果物の格納先・命名規約など）

> 規約・スキルを書く側の規約（どこをマーカーで囲み、どこを `*-details.md` に分離するか）は `.claude/docs/authoring-guide.md`「モデル別プロファイルへの対応」を参照。
