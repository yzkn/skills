# 指令リポジトリ

複数の案件・複数の PC・複数のエージェント（Claude Code、Copilot など）をまたいで、**依頼と作業の状態**を Markdown で管理するリポジトリです。コードは置きません。

- 人が書くところ: `inbox.md`（新しい依頼）、タスクファイルの「利用者への質問と回答」「決定事項」
- エージェントが書くところ: タスクファイル（`projects/<案件>/tasks/*.md`）の状態・計画・ログ
- エージェント向けの決まり: [AGENTS.md](AGENTS.md)　承認の境界: [policy.md](policy.md)

## 依頼の出し方（人）

どれでも構いません。

| 方法 | やること |
|---|---|
| **受付に書く**（いちばん手軽。スマートフォンの GitHub からでも） | [inbox.md](inbox.md) の末尾に `## <案件>: <件名>` と本文を足してコミットする。エージェントが次の機会にタスクファイルへ起こす |
| **エージェントに直接頼む** | 会話でそのまま頼む。エージェントがタスクファイルを作り、状態をここに反映する |
| **タスクファイルを自分で作る** | `templates/task.md` を `projects/<案件>/tasks/<日付>-<短い名前>.md` に写して書く。書きかけの間は `status: draft` にしておく |

依頼には、できれば**段階**を書いてください（書かなければ「提案だけ」として扱います）。

| 段階 | 書き方 | エージェントが進めてよい範囲 |
|---|---|---|
| 提案だけ | `段階: 提案だけ`（`propose`） | 調査と提案。変更は加えない |
| 実装まで | `段階: 実装まで`（`implement`） | 作業ブランチで実装し、PR / MR を作るところまで。マージしない |
| マージまで | `段階: マージまで`（`merge`） | PR / MR のマージまで |

## 途中で口を挟む（人）

- **質問に答える**: 状態が `waiting` のタスクは、ファイルの「利用者への質問と回答」に質問が書いてあります。その場に答えを書いてコミットすれば、エージェントが次に読んで続けます
- **方針を変える・止める**: タスクファイルの「決定事項」に 1 行足す。止めるなら `status: dropped` に書き換える
- **担当を変える**: `assignee:` にエージェントの ID（[roster.md](roster.md)）か、道具の名前（`claude` / `copilot`）を書く。誰でもよければ `any`

## 状態の見方

| `status` | 意味 | 人の対応 |
|---|---|---|
| `draft` | 人が書きかけ。エージェントは触らない | 書き終えたら `ready` に |
| `ready` | 着手できる | — |
| `doing` | エージェントが作業中（`claimed_by` が担当） | — |
| `waiting` | **利用者の判断・承認を待っている** | 質問に答える |
| `blocked` | 外部の要因で進めない（認証切れ・権限・障害） | 原因を取り除く |
| `done` / `dropped` | 完了 / 取りやめ（`archive/` に移る） | — |

一覧は、エージェントに「ループの状態を見せて」と頼むか、`status.ps1` を実行します。

## 構成

```
inbox.md                     受付（人が追記する）
roster.md                    エージェントの名簿（PC・道具・アカウント）
policy.md                    承認の境界（全案件に共通）
AGENTS.md / CLAUDE.md        エージェント向けの決まり
templates/                   タスク・案件・委任の指示書・報告のひな形
projects/<案件>/
  project.md                 案件の定義（リポジトリ・アカウント・検証の方法・落とし穴）
  tasks/<ID>.md              タスク = 状態ファイル（1 タスク 1 ファイル）
  archive/<ID>.md            完了・取りやめ
```

## 置いてはいけないもの

- 認証情報（トークン・パスワード・鍵）、個人情報
- コード・大きなファイル・一時ファイル（各 PC の `~/.claude/auto-loop/work/<タスク ID>/` に置く）
