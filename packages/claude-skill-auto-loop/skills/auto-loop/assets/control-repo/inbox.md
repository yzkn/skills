# 受付

新しい依頼を、この下に足してください。エージェントが次の機会にタスクファイルへ起こし、ここからは消します。

書き方（見出しの 1 行だけが必須。あとは自由）:

```markdown
## <案件>: <件名>
段階: 提案だけ | 実装まで | マージまで      ← 省くと「提案だけ」
担当: any | claude | <エージェントの ID>     ← 省くと any
優先: 高 | 普通 | 低                          ← 省くと普通

（やってほしいこと・完了の条件・やらないこと・参考の場所を自由に）
```

- 案件は `projects/` のフォルダ名。新しい案件なら `## 新規: <件名>` と書き、リポジトリの場所を本文に書く
- 進行中のタスクへの追加の指示は、ここではなく、そのタスクファイルの「決定事項」に書く
