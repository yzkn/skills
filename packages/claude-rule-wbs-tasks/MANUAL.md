## 3. 導入手順

```sh
mkdir -p .claude/rules
cp rules/wbs-tasks.md .claude/rules/
```

常時適用したい場合は `CLAUDE.md` に `@.claude/rules/wbs-tasks.md` の行を追加する。frontmatter に `paths:` があるルールは `@` 行に**加えない**（加えると常時ロードになり、条件付きの意味が失われる）。

## 4. 内容の構成

本体（`rules/wbs-tasks.md`）の見出し構成:

- 1. データソースの一元化
- 2. ID の採番規則
- 3. 依存関係の参照整合性
- 4. ステータス遷移と日付・進捗の連動
- 5. フェーズ行（親）の扱い
- 6. マイルストーン
- 7. 編集後の整合性セルフチェック
- 進捗管理資料の格納場所
