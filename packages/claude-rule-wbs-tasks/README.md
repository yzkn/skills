# wbs-tasks

WBS・課題管理表の編集規約。ID 採番・依存関係の整合性・ステータス遷移と日付/進捗の連動を定義する。task/ 配下のファイルを扱う際に自動ロードされる。

> このリポジトリは、Claude Code 用のプロジェクトテンプレート `claudecode-pm-starter-kit`（非公開）の資産を **1 項目 = 1 リポジトリ**の形に切り出したものである。切り出しは機械的に行っており、**本文中の相互参照は元リポジトリのパスのまま残っている場合がある**（下記「単体利用時の注意」を参照）。元リポジトリは公開していないため、本文が挙げる ADR・コミットなどの記録は参照できない。

## これは何か

WBS の ID 採番・依存参照の整合・ステータス遷移と日付 / 進捗の連動・編集後セルフチェック

## なぜ作られたか

同上（ADR-003）。**WBS のデータ規約が無いため `sprint-planner` の生成物の形式が揺れていた**ことが動機

## 導入

```sh
mkdir -p .claude/rules
cp rules/wbs-tasks.md .claude/rules/
```

常時適用したい場合は `CLAUDE.md` に `@.claude/rules/wbs-tasks.md` の行を追加する。frontmatter に `paths:` があるルールは `@` 行に**加えない**（加えると常時ロードになり、条件付きの意味が失われる）。
