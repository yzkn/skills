# サードパーティライセンス — 詳細編（常時ロードしない）

`.claude/rules/third-party-licenses.md`（常時適用）から分離した分類表。**持ち込み可否の判断に迷うとき・ライセンス名が下表のどれに当たるか確認したいときに Read する**。判断基準そのもの（確認義務・【要指示】の範囲）は常時適用側に残してある。

## 原則として持ち込んでよいライセンス

商用利用可能で、**ソースコードの開示義務（コピーレフト）がない** permissive ライセンスに限る。

| 分類 | 代表例 |
|---|---|
| Permissive | MIT、BSD（2-Clause / 3-Clause）、Apache License 2.0、ISC |
| パブリックドメイン相当 | 0BSD、Unlicense、CC0 |

- Apache 2.0・BSD 等が求める**帰属表示・ライセンス全文・`NOTICE` の同梱義務**は必ず遵守する（`LICENSE` / `NOTICE` を成果物に含める）

## 【要指示】 持ち込みにユーザーの明示的な指示が必要なライセンス

以下は上記「原則」の例外にあたり、Claude Code の判断で持ち込んではならない。持ち込みが技術的に必要な場合は、**トレードオフ（開示義務・派生物の扱い・商用上の制約）を提示してユーザーの明示的な指示を得たうえで**、`/record adr` で採否の根拠を `./doc/adr/` に記録する。

| 分類 | 代表例 | 主な制約 |
|---|---|---|
| 強いコピーレフト | GPL（v2 / v3）、AGPL、SSPL | 派生物・改変物のソースコード開示義務。AGPL はネットワーク提供時も対象 |
| 弱いコピーレフト | LGPL、MPL 2.0、EPL、CDDL | 改変部分・特定ファイルの開示義務、動的リンク条件等 |
| 商用制限付き | BUSL（Business Source License）、Commons Clause 付与 | 商用利用・SaaS 提供の制限 |
| プロプライエタリ / ライセンス不明 | 独自 EULA、ライセンス表記なし | 利用条件が個別・不明。無許諾利用は権利侵害 |

## 補足

- 確認元は原則として一次情報（配布元リポジトリの `LICENSE` ファイル、パッケージメタデータの `license` フィールド、公式ドキュメント）とする
- 依存関係が推移的に引き込む二次依存（transitive dependencies）のライセンスも確認対象とする
- 採用したサードパーティのライセンスは、依存定義ファイル（`package.json`・`requirements.txt`・`*.csproj` 等）または設計書で追跡可能にする
- ライセンスリスク・既知 CVE・EOL の継続的な監査は `dependency-auditor` サブエージェント（SCA）を使用する
