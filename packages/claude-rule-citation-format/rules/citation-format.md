# 引用・典拠の書式（パス条件付き適用）

`design/`・`report/` 配下の文書で外部ソース（受領資料・規格文書・記事・Web ページ）を引用するときは、以下に従う。

- **引用はコードブロック（フェンス）の中に置く。`>` の blockquote 記法は使わない**
- 原典が日本語でない場合、原文と訳文を**同じコードブロック内**に空行 1 つで区切って並置する（水平線 `---` を挟まない）
- 典拠参照 `[label (YYYY/MM), 位置]` は**終了フェンスの次の行**に独立した行として置く。コードブロックの中に入れない
- **`[1]`・`[2]` のような裸の番号参照は使わない**。情報源を直接示す `label` を使う
- 文書末尾の典拠一覧は `/research` と同じ信頼性付きの表形式（🟢🟡🔴 / 情報源 / URL・所在 / 参照箇所）で書く
- 事実的記述には典拠を付ける。結び付けられない場合は「典拠未確認」と明示する。原典が書いていない関連付け・解釈を原典の説明として書かない

書式の詳細・記入例・アンチパターン一覧は [`.claude/skills/citation-format/SKILL.md`](../skills/citation-format/SKILL.md) を Read する。
