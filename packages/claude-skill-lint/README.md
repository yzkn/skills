# /lint

コーディング規約への準拠をチェックする。静的解析ツールを優先実行し、ツールで検出できない点を補足する。「lint して」「規約チェックして」で自動適用。構造的レビューは /project-code-review。

> このリポジトリは、Claude Code 用のプロジェクトテンプレート `claudecode-pm-starter-kit`（非公開）の資産を **1 項目 = 1 リポジトリ**の形に切り出したものである。切り出しは機械的に行っており、**本文中の相互参照は元リポジトリのパスのまま残っている場合がある**（下記「単体利用時の注意」を参照）。元リポジトリは公開していないため、本文が挙げる ADR・コミットなどの記録は参照できない。

## 導入

```sh
# 導入先のプロジェクトルートで実行する
mkdir -p .claude/skills
cp -r skills/lint .claude/skills/
```

**スキルは必ずディレクトリ形式（`.claude/skills/lint/SKILL.md`）で置く。** フラットな `.md` として置くとスキル登録機構に載らず、自動適用も `/lint` での呼び出しもできない。

## 使い方

`/lint` で明示的に呼び出す。frontmatter の `description` に一致する依頼で自動適用もされる。
