# /file-lock

編集・削除すべきでないファイルを OS レベルでロック・解除・状態確認する。「ファイルをロックして」「編集禁止にして」「ロックを解除して」で自動適用。/file-lock <lock|unlock|status> [パス...]。

## 導入

```sh
# 導入先のプロジェクトルートで実行する
mkdir -p .claude/skills
cp -r skills/file-lock .claude/skills/
```

**スキルは必ずディレクトリ形式（`.claude/skills/file-lock/SKILL.md`）で置く。** フラットな `.md` として置くとスキル登録機構に載らず、自動適用も `/file-lock` での呼び出しもできない。

## 使い方

`/file-lock` で明示的に呼び出す。frontmatter の `description` に一致する依頼で自動適用もされる。
