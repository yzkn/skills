# /design-sync

新情報（議事録・追加資料・意思決定）を設計書と WBS に反映する。差分を提示し、合意後に反映する（合意前に既存ファイルを変更しないことが鉄則）。「議事録から設計書を更新して」「sync して」で自動適用。/design-sync。

## これは何か

新情報（議事録・追加資料・意思決定）と既存の設計書・WBS の差分を提示し、**合意後に反映する**（合意前の変更禁止）

## なぜ作られたか

姉妹キット `ppf-pm-kit` との比較調査で、**顧客受領資料・議事録を設計に取り込む工程（インテーク → 抽出 → 差分反映）が未定義**だったことが判明（ADR-003）。後に議事録からのアクションアイテム抽出（担当・期限）と `task/` への反映案提示を必須ステップ化した（コミット `d8feaef`）

## 導入

```sh
# 導入先のプロジェクトルートで実行する
mkdir -p .claude/skills
cp -r skills/design-sync .claude/skills/
```

**スキルは必ずディレクトリ形式（`.claude/skills/design-sync/SKILL.md`）で置く。** フラットな `.md` として置くとスキル登録機構に載らず、自動適用も `/design-sync` での呼び出しもできない。

## 使い方

`/design-sync` で明示的に呼び出す。frontmatter の `description` に一致する依頼で自動適用もされる。

## 収録ファイル
