# compliance-checker リファレンス — 法令・基準別チェック項目表・レポートフォーマット

compliance-checker エージェントから参照されるリファレンス。エージェント定義本体は `.claude/agents/compliance-checker.md`。
各法令・基準の診断前に該当セクションを Read し、記載のチェック項目表に従って診断すること。

## 個人情報保護法（日本）のチェック項目

#### 3-1: 個人情報の取り扱い

| チェック項目 | 確認内容 | 適合基準 |
|---|---|---|
| 利用目的の特定 | 収集する個人情報の利用目的が設計書に明示されているか | 設計書に利用目的の記載あり |
| 利用目的の通知・公表 | プライバシーポリシーの実装・設計が存在するか | プライバシーポリシー画面の設計書あり |
| 目的外利用の禁止 | 収集目的以外の用途でデータを使用しないことが設計書に明記されているか | 設計書に制約として記載あり |
| 第三者提供の同意 | 第三者へのデータ提供に同意機能が設計されているか | 同意取得フローの設計あり |
| 開示請求への対応 | データ主体からの開示・訂正・削除リクエストに対応する機能が設計されているか | 管理機能の設計あり |
| 安全管理措置 | 個人情報の漏洩・滅失防止のためのセキュリティ設計があるか | 暗号化・アクセス制御の設計あり |
| 委託先管理 | 外部サービス（クラウド等）への個人データ委託に関する設計・記録があるか | 委託先一覧・契約確認の記録あり |
| 匿名加工・仮名加工 | 分析用途のデータに匿名化・仮名化の処理が設計されているか | 匿名化処理の実装・設計あり |

#### 3-2: 要配慮個人情報の特別管理

以下のデータを扱う場合は特別な保護措置が必要。

| 種別 | 例 |
|---|---|
| 要配慮個人情報 | 人種・信条・病歴・犯罪歴・障害・健康診断結果 |
| 機密性の高い情報 | マイナンバー・パスポート番号・運転免許番号 |

## GDPR のチェック項目

#### 4-1: 合法性の根拠（Legal Basis）

| チェック項目 | 確認内容 |
|---|---|
| 処理の根拠の明確化 | 同意 / 契約履行 / 法的義務 / 正当な利益 のいずれかが設計書に明示されているか |
| 同意の取得 | 自由意思・明確・情報に基づいた同意を取得する設計があるか |
| 同意の撤回機能 | 同意を撤回する機能（オプトアウト）が設計されているか |

#### 4-2: データ主体の権利（Data Subject Rights）

| 権利 | 確認内容 |
|---|---|
| アクセス権 | ユーザーが自分のデータを取得できる機能の設計があるか |
| 訂正権 | ユーザーが自分のデータを修正できる機能の設計があるか |
| 消去権（忘れられる権利） | ユーザーが自分のデータを削除できる機能と、関連データの連動削除の設計があるか |
| データポータビリティ | ユーザーが自分のデータを機械可読形式（JSON等）でエクスポートできる設計があるか |
| 処理制限権 | データ処理を制限するフラグの設計があるか |
| 異議申し立て権 | プロファイリング等への異議申し立てに対応する設計があるか |

#### 4-3: プライバシー・バイ・デザイン

| チェック項目 | 確認内容 |
|---|---|
| データ最小化 | 目的に必要な最小限のデータのみを収集する設計になっているか |
| 保存期間の制限 | データの保存期間が設計書に定義されており、期間超過後の削除処理が設計されているか |
| データ保護影響評価（DPIA） | 高リスク処理について DPIA の実施記録または計画があるか |
| プロファイリングの通知 | 自動的な意思決定・プロファイリングを行う場合にユーザーへの通知設計があるか |

## PCI DSS のチェック項目

| チェック項目 | 確認内容 |
|---|---|
| カードデータの保存範囲 | カード番号（PAN）・CVV・有効期限を自社 DB に保存していないか |
| 暗号化 | 決済 API 通信が TLS 1.2 以上で暗号化されているか |
| トークン化 | カード情報を決済代行サービスのトークンに置き換えているか |
| アクセス制御 | 決済関連の API・管理画面へのアクセスが最小権限で制御されているか |
| ログの適切な管理 | ログにカード番号・CVV が出力されていないか |

## ISO 27001 のチェック項目

| 管理策 | チェック内容 |
|---|---|
| A.9 アクセス制御 | 役割ベースのアクセス制御（RBAC）の設計があるか |
| A.10 暗号化 | 機密データの暗号化方針が設計書に定義されているか |
| A.12 運用セキュリティ | バックアップ・変更管理・マルウェア対策の設計があるか |
| A.13 通信のセキュリティ | すべての外部通信が TLS で暗号化されているか |
| A.16 情報セキュリティインシデント管理 | インシデント対応手順書が存在するか（`design/08_operations/`） |
| A.17 事業継続管理 | BCP・DR の設計があるか |
| A.18 コンプライアンス | 法令・規制への適合確認プロセスが存在するか |
