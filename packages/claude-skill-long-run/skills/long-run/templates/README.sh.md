# 長時間ジョブ: {{ID}}

セッションリミット（5時間枠）に強い detach 実行ジョブです。処理は OS 側で自走するため、Claude Code のセッションが切れても継続し、解除後に `check.sh` で結果を確認できます。

## 使い方（Linux / macOS）

1. 起動:   `bash run.sh`
2. 状態確認（何度でも・別セッションでも可）:   `bash check.sh`

## 完了判定

- `exit.code` が生成されていれば完了（ファイル内容が終了コード。`0`=成功）
- 実行中は `job.pid` のプロセスが生存
- プロセス消滅かつ `exit.code` なし = 中断/異常終了 → `stderr.log` を確認

## セッションリミットに当たったら

新しいセッションで `bash check.sh` を実行するだけで状態を再確認できます（`run.sh` の再実行は不要）。

## 後片付け

確認が済んだらこのディレクトリごと削除して構いません（`.jobs/` は `.gitignore` 済み）。
