## 導入

```sh
# 導入先のプロジェクトルートで実行する
mkdir -p .claude/skills
cp -r skills/ghostwriter .claude/skills/
```

**スキルは必ずディレクトリ形式（`.claude/skills/ghostwriter/SKILL.md`）で置く。** フラットな `.md` として置くとスキル登録機構に載らず、自動適用も `/ghostwriter` での呼び出しもできない。

## 使い方

`/ghostwriter` で明示的に呼び出す。frontmatter の `description` に一致する依頼で自動適用もされる。
