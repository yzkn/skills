棒グラフ
棒グラフのルール: 量の大小を比較するときに使う。縦軸は必ず 0 を基準にする（途中から始めると差が誇張される）。 棒の幅を揃え、プレゼンでは縦軸・目盛線を省略して棒の上にラベルを置くとシンプルになる。 円グラフよりも量の差が直感的に伝わる。

折れ線グラフ
折れ線グラフのルール: 量の増減（時系列変化）を比較するときに使う。縦軸は 0 から始めなくてよい。 横軸は等間隔の時系列にする。各線にマーカーを設定し、凡例で区別する。 系列が複数ある場合は色と線種（実線・破線）を組み合わせると区別しやすい。
