# /ghostwriter スキル — ゴーストライター（文章執筆支援）

文章執筆ガイドライン（社内文書・プレゼンテーション資料編）に基づき、ユーザーの代わりに文書・資料を執筆または校正する。

## 呼び出し方

```
/ghostwriter <文書の目的・要求>
```

**使用例**
- `/ghostwriter 顧客向けの障害報告書を書いてください。内容は…`
- `/ghostwriter 経営層向け提案書のストーリーを作ってください`
- `/ghostwriter この下書きを整形してください: [テキスト]`
- `/ghostwriter プレゼン資料の流れを PREP 法で組み立ててください`

---

## Step 1: 執筆前の確認

以下が不明な場合は執筆を開始する前にユーザーに確認する。

| 確認事項 | 選択肢・補足 |
|---|---|
| **目的** | 指示・指令 / 通知・案内 / 稟議 / 報告 / 申請 / 提案・説得 / 議事録 / 解説 |
| **ターゲット** | 顧客 / 上司・経営層 / 同僚 / 部下 |
| **ファイル形式** | Word 文書 / PowerPoint / メール / チャット |
| **緊急度** | 同期型（口頭・会議）の補足が必要か否か |

**経営層向けの追加要件**
- 要点が簡潔にまとまっている（ボリューム少）
- 結論から入る
- 根拠が定量的（数字）
- コストと効果が明確

---

## Step 2: 文体の決定

1 つの文書に複数の文体を混在させない。

| 文体 | 用途 |
|---|---|
| 文語体（です・ます） | 顧客向け・目上向け・公式文書 |
| 常体（だ・である） | 社内技術文書・設計書・報告書 |
| 口語体 | ブログ等カジュアルな文書の地の文 |

ブログ等では地の文を口語体、箇条書き・図表・コラムを文語体にしてメリハリをつけてよい。

## Step 7: 著作権・引用ルール

以下の条件を**すべて**満たす場合のみ、著作物を「引用」できる:

1. 自分の著作物が主、引用部分が従の関係にある
2. 引用部分と自分の著作部分を明確に区別する（段落・フォント・括弧など）
3. 引用は必要最小限にとどめる
4. 引用元の原文を改変しない
5. 出典（著者・書名・発行年・URL など）を明記する

**引用が許容される目的の例**: 批評・解説・教育目的の短い引用、研究目的の文章引用

**コピーは引用ではない**: 単純に文章をコピーして使用することは著作権侵害になる。

## Step 8: 自己レビューチェックリスト

生成した文書を出力する前にセルフチェックする。

### 共通チェック

- [ ] 目的・ターゲットに合った文体・表現か
- [ ] 文体が統一されているか（です・ます / だ・である の混在なし）
- [ ] 漢字かな使い分けが規則通りか（補助動詞・形式名詞はひらがな）
- [ ] 数字の表記が正しいか（算用数字、3 桁カンマ、万億兆は漢字）
- [ ] 英語固有名詞の表記が公式表記通りか
- [ ] 指示語が明確か（「それ」「これ」の指す対象が読み手に伝わるか）
- [ ] 接続詞が適切に使われているか（省略して曖昧になっていないか）
- [ ] ぎなた読みが発生しないか
- [ ] 修飾語と被修飾語が近接しているか
- [ ] 二重否定・部分否定を使っていないか
- [ ] 「から」「より」の使い分けが正しいか
- [ ] 主語が明確か（責任の所在が明確な文書）
- [ ] 定性的表現（とても・かなり・非常に）が混入していないか
- [ ] 結論が先頭にあるか
- [ ] 論点と補足情報が分離されているか
- [ ] タイトルが具体的か（「〜について」になっていないか）
- [ ] 図表に番号とタイトルがあり、本文と数値・単位・用語が一致しているか
- [ ] 表に理由のない空欄がないか（数字は右揃え・小数点以下の桁がそろっているか）
- [ ] 色だけで系列を区別していないか（白黒でも読めるか）

### プレゼン資料（追加チェック）

- [ ] 1 スライドに 1 トピックか
- [ ] まとめスライドがあり、結論を再掲しているか（「ご清聴ありがとうございました」のみで終わっていないか）
- [ ] グラフの縦軸が 0 基準か（棒グラフ）
- [ ] ドーナツグラフ・3D 円グラフを使っていないか
- [ ] 前提条件・制約条件が明記されているか（提案書・契約関連の場合）
- [ ] 整列・近接・反復のレイアウト原則が守られているか
