# app-theme-proposer

アプリ実装テーマ提案エージェント。「何を作るか決まっていない」ユーザーに 5 問ヒアリングし、テーマ候補を比較表で提示する。確定後は仕様書とワイヤーフレームを生成する。コードは変更しない。

> このリポジトリは、Claude Code 用のプロジェクトテンプレート `claudecode-pm-starter-kit`（非公開）の資産を **1 項目 = 1 リポジトリ**の形に切り出したものである。切り出しは機械的に行っており、**本文中の相互参照は元リポジトリのパスのまま残っている場合がある**（下記「単体利用時の注意」を参照）。元リポジトリは公開していないため、本文が挙げる ADR・コミットなどの記録は参照できない。

## これは何か

5 問ヒアリング後にアプリ実装テーマ候補 5 件を Artifact 比較表で提示し、確定テーマの仕様書とワイヤーフレームを生成

## なぜ作られたか

2026-06-25 追加（記録なし）。「何を作るか決まっていない」利用者向け。ADR-008・ADR-010 の教育系パターン検討で補完対象として言及されている

## 導入

```sh
mkdir -p .claude/agents
cp agents/app-theme-proposer.md .claude/agents/
```

**`.claude/agents/` はフラットに置く**（サブディレクトリを作っても登録機構は再帰的に走査するため、無効化の目的では使えない）。

## 使い方

Agent ツールで `subagent_type: "app-theme-proposer"` を指定して起動する。
