# /deploy-guide スキル — CI/CD とデプロイメント方針

CI/CD パイプラインの構成方針とデプロイ・ロールバックのルールを定義する。

## 適用方法

`/deploy-guide` で直接呼び出せるほか、CI/CD・デプロイ・ロールバックの作業時に Claude Code が自動参照し、「デプロイ手順を確認して」のような依頼でも適用される。

---

## パイプラインの基本構成

<!-- profile:standard-only 一般的な CI/CD パイプラインの段構成 -->

```
コミット → ビルド → 静的解析 → 単体テスト → 結合テスト → ステージングデプロイ → 本番デプロイ
```

- 各ステップは前のステップが成功した場合のみ続行する
- ステージングデプロイまでは自動実行を推奨する

<!-- /profile:standard-only -->

- **本番デプロイは手動承認（マニュアルゲート）を設ける**

---

## デプロイのルール

- 本番デプロイはユーザーの明示的な承認後に実行する（`.claude/rules/environment-safety.md`「本番デプロイの必須承認」準拠）
- デプロイ前にヘルスチェック URL が正常応答することを確認する
- デプロイ後は主要機能のスモークテストを実施する

---

## ロールバック

- 本番デプロイ後に重大な障害が発生した場合、ロールバックを優先する
- ロールバック手順は事前に文書化し `docs/` に配置する
- ロールバック判断基準（例: エラーレート閾値・応答時間超過）をプロジェクト開始時に定義する
